# AI 1v1 测试门槛

## 当前状态

入口位于多人游戏的 `1v1` 页面内，是一个独立的测试按钮，不是第五种多人模式。
当前按钮只用于确认授权和 UI 位置，尚未创建 AI 房间，也不会改变真人匹配、统计或
花阶分。

## 开启条件

测试服启动游戏服务前设置：

```powershell
$env:GTN_AI_1V1_TEST_ENABLED = '1'
```

玩家还必须在当前浏览器开启“特别致谢”，并通过隐藏功能密码接口取得服务端签名会话。
前端会请求 `/api/hidden-features/status`；只有响应中的 `ai_1v1_test` 为 `true` 且当前
模式为 `1v1` 才展示按钮。接口返回 `Cache-Control: no-store`，关闭功能时前端立即隐藏。

生产服不设置该环境变量时，入口对所有玩家不可见，包括已经解锁特别致谢的玩家。

## 真正接入时

后续建房流程建议继续使用正式 `GameEngine`，将 AI 作为服务端控制的第二座位：

1. 创建不进入真人匹配队列的普通 1v1 房间
2. 真人照常完成配装与选牌，AI 通过 sidecar 完成相同阶段
3. 每次请求前由游戏服务生成公开观测和完整合法动作
4. 对 sidecar 返回值做合法集合复验，失败时使用启发式策略
5. 不计 GR；单独记录模型版本、规则指纹、超时和回退率
6. 离开、重连、观战、回放和结算继续复用正式 1v1 路径

在模型通过擂台、并发延迟与稳定性门槛之前，不应把这个入口接到真人匹配。
